# 1176 JUCE implementation plan

**Goal:** Deliver locally built macOS Standalone, AU and VST3 implementing the approved v6 design and real fetcomp-dsp audio.
**Architecture:** A JUCE AudioProcessor owns APVTS and DspEngine. DspEngine owns the pinned upstream FET processor, delayed dry bypass and fixed-capacity MeterBridge. A native editor consumes meter frames and shares APVTS between two visual layouts.
**Tech stack:** C++17, CMake, JUCE 8.0.12 (29396c22c93392d6738e021b83196283d6e4d850), fetcomp-dsp de18f5ac793e36397c725abdca7fcb8c08760ce2.
**Spec:** design/DESIGN.md, design/panel-reference.css, approved v6 preview.

## Constraints
- Keep approved neutral textures and proportions (1280×334 Rack, 1280×508 Dynamic), larger gain knobs, circular rim-only focus and rectangular ratio/meter buttons.
- Real stereo-linked FET DSP; no simulation in product UI.
- Mono and stereo. No allocations/locks in processBlock. Smooth input/output and bypass. Report and compensate oversampling latency.
- inputDb -20..40, outputDb -20..20, attackUs 20..800 clockwise faster, releaseMs 50..1100 clockwise faster, ratio four choices, allButtons separate bool, bypass separate bool.
- Persist parameters and UI view; host automation updates UI; switching layouts never resets DSP.

## Shared contracts
`field::MeterFrame` has `std::array<float,2> inputDb/outputDb/inputRmsDb/outputRmsDb` (silence -100), `float reductionDb` (positive), `uint64_t sequence` and `bool bypassed`.
`field::MeterBridge::pop(MeterFrame&) noexcept -> bool` is UI consumer, `push(const MeterFrame&) noexcept -> bool` is audio producer; bounded SPSC, safe concurrent operation, no allocation; producer never advances consumer index.
`field::DspEngine::Settings`: inputDb/outputDb/attackUs/releaseMs floats; ratioIndex int 0..3; allButtons/bypass bool. Methods prepare(double,int,int), reset(), process(juce::AudioBuffer<float>&,const Settings&,bool hostBypassed=false), getLatencySamples() const noexcept, meters() noexcept -> MeterBridge&.
`FieldEffectProcessor` public `juce::AudioProcessorValueTreeState parameters`, `field::MeterBridge& meterBridge() noexcept`, `std::atomic<int> editorMode{0}`, `std::atomic<int> editorWidth{1280}`. Editor constructor `FieldEffectEditor(FieldEffectProcessor&)`. BinaryData names from assets: conceptknobbody_png, conceptmetal_jpg, conceptvupaper_jpg (inspect generated BinaryData header).
