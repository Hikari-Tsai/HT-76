# Download badge icons

The README uses Shields.io badges with these icons:

- **AAX — Pro Tools:** the `protools` icon from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/protools.svg), served by Shields.io.
- **VST3 — Cubase:** the symbol from Steinberg's [official Cubase family logo](https://ocl-steinberg-live.steinberg.net/_storage/asset/66148/storage/master/Cubase-generic-500px-color.svg), linked from the [Cubase product page](https://www.steinberg.net/cubase/). The symbol is cropped from the wordmark and recolored to match the badge.
- **AU — Audio waveform:** an original monochrome SVG with five rounded vertical bars, chosen for legibility at badge size. It represents audio, not an official Apple, Logic Pro, or Audio Units logo.

The Cubase symbol and AU waveform are embedded in the Shields.io image URLs. Product marks belong to their respective owners; those marks are not original HT-76 artwork. They identify familiar hosts and do not indicate endorsement or restrict the plug-in formats to those hosts. AAX signing and host compatibility limitations are documented in the README.
